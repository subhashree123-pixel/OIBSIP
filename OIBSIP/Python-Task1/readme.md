BMI Calculator

Overview

The BMI Calculator is a Python application that calculates a user's Body Mass Index (BMI) using their weight and height. It also classifies the BMI into standard health categories.

Features

- Accepts weight (kg) and height (m) as input
- Calculates BMI using the standard formula
- Displays BMI rounded to two decimal places
- Classifies BMI as Underweight, Normal, Overweight, or ObeseA
- Handles invalid and negative inputs with appropriate error messages

Technologies Used

- Python 3

Formula

BMI = Weight (kg) / Height² (m²)

How to Run

1. Install Python 3.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run the program:
   python bmi_calculator.py

Sample Output

Enter your weight (kg): 60
Enter your height (m): 1.65

Your BMI is: 22.04
